# Revenue Pilot(by OVERA) — 共有バックエンド版

これまでブラウザ内(IndexedDB)だけに保存していたデータを、**サーバー上の1つのファイルに保存**するように変更したものです。
これにより、同じサーバーにアクセスすれば、どの端末・誰が見ても同じデータになります。

## 構成

```
revenue-pilot-app/
├── server.js         ← APIサーバー本体(データの保存・取得)
├── package.json
├── public/
│   └── index.html    ← 画面(これまでと同じ見た目・操作感)
└── data/              ← ここにデータが自動保存される(初回起動時に作成)
    ├── all_data.json
    └── settings.json
```

Excelの読み込み・パース処理は**これまで通りブラウザ側**で行います。サーバーは「みんなで見る保存場所」の役割だけを持ちます。DB(SQLite等)のインストールが不要なので、Node.jsさえ動けばどんな環境でもそのまま動きます。

## 一番簡単な始め方(Windows・ダブルクリックのみ)

1. Node.js が入っていない場合は、まず [nodejs.org](https://nodejs.org/ja) から「推奨版(LTS)」をインストール(1回だけ)
2. このフォルダの中の **`start.bat`** をダブルクリック
   - 初回は自動でセットアップが始まります(少し時間がかかります)
   - 併せて、ロゴ入りのデスクトップショートカット「Revenue Pilot」も自動で作成されます
   - 完了すると自動でブラウザが開きます
3. 次回からはデスクトップにできた **「Revenue Pilot」ショートカット**をダブルクリックするだけで起動します

黒い画面(コマンド画面)が開いたままになりますが、これはサーバーが起動している間ずっと表示されているものです。**この画面を閉じると、他の人からもアクセスできなくなる**のでそのままにしておいてください。使い終わったら閉じてOKです。

同じWi-Fi内の他のPC・スマホから見る場合は、`start.bat` を実行しているPCで `ipconfig` を実行して出てくる `IPv4アドレス`(例: `192.168.1.10`)を使い、他の端末で `http://192.168.1.10:3000` を開いてください。

## 手動で行う場合(上級者向け)



```bash
cd revenue-pilot-app
npm install
npm start
```

`http://localhost:3000` にアクセス。同じLAN内の他のPC/スマホからは `http://<このPCのIPアドレス>:3000` でアクセスできます(例: `http://192.168.1.10:3000`)。

## 2. 社内サーバー/常時稼働PCで動かす

上と同じ手順ですが、再起動しても自動で立ち上がるように [pm2](https://pm2.keymetrics.io/) の利用をおすすめします。

```bash
npm install -g pm2
pm2 start server.js --name revenue-pilot
pm2 save
pm2 startup   # 表示されるコマンドを実行するとOS起動時に自動起動
```

## 3. クラウドにデプロイする場合

Node.jsが動くPaaS(Render、Railway、Fly.ioなど)であれば、このフォルダをそのままGitリポジトリにpushしてデプロイするだけで動きます。

- ビルドコマンド: `npm install`
- 起動コマンド: `npm start`
- ポート: 環境変数 `PORT` を自動で見てくれるサービスがほとんどです(このサーバーは `process.env.PORT` に対応済み)

**注意**: 上記PaaSの多くは、デプロイのたびにファイルシステムがリセットされる「エフェメラルストレージ」です。`data/` フォルダの中身が消えてしまう可能性があるため、本番運用する場合は、そのサービスの「永続ディスク(Persistent Disk / Volume)」機能を有効にして `data/` フォルダをそこに向けてください(具体的な設定は使うサービスによって異なるので、決まったら相談してください)。

## データを外部に公開したくない場合(簡易パスワード)

社外からもアクセスできる場所に置く場合は、簡単な合言葉で保護できます。

```bash
BOOKING_CURVE_KEY="好きな合言葉" npm start
```

この場合、`public/index.html` 内のAPI呼び出し(`apiGet`/`apiPost`/`apiDelete`)に `x-api-key` ヘッダーを付ける必要があります。有効にする場合はお知らせください、フロント側も合わせて修正します。

## アイコンについて

ブラウザタブのアイコン(favicon)は、いただいたロゴ画像から自動的に設定済みです。ブラウザで開くと反映されます。

**デスクトップのアイコン付きショートカットも自動作成されます**: 新しいPCで初めて `start.bat` を実行すると(＝インストール時)、自動でデスクトップに「Revenue Pilot」というロゴ入りショートカットが作られます。2回目以降はそのショートカットから起動できます(`start.bat`を直接使い続けても問題ありません)。

もしショートカットを手動で作り直したい場合は、`create-desktop-shortcut.bat` を単体でダブルクリックしてください。

## トラブルシューティング


### 「npm : このシステムではスクリプトの実行が無効になっているため…」というエラーが出る

これはPowerShellの初期セキュリティ設定により、`npm`コマンドが`npm.ps1`として実行されブロックされるために起こります。対処法は2つあります。

**方法A(おすすめ)**: `start.bat` をダブルクリックして使ってください。内部で `npm.cmd` を明示的に呼ぶようにしているため、この問題が起きません。PowerShellで直接 `npm install` などを打つのは避けてください。

**方法B**: どうしてもPowerShellでコマンドを打ちたい場合は、PowerShellを**管理者として起動**し、以下を一度だけ実行してください(以降は制限が解除されます)。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## API一覧(参考)

| メソッド | パス | 内容 |
|---|---|---|
| GET | /api/data | 保存されている全データを取得 |
| POST | /api/data | 新しいスナップショット点をマージ保存 `{points:[{stayISO,snapshotISO,rooms,sales,adr,revpar}]}` |
| DELETE | /api/data | 全データ削除 |
| GET / POST | /api/settings | 総客室数などの設定 |
| GET | /api/health | 稼働確認用 |
